# Logos des marques sur les cartes articles

Ce dossier est commun au catalogue (toutes categories) et aux arrivages de
l'accueil connecte. Les fichiers sont detectes automatiquement au chargement
de la page, sans modifier de table de correspondance ni la base de donnees.

## Ajouter une marque

1. Prendre le nom exact du champ Marque de l'article.
2. Le mettre en minuscules, retirer les accents et remplacer les espaces ou
   ponctuations par un seul tiret. Pas de tiret au debut ou a la fin.
3. Deposer le vrai logo dans ce dossier, puis recharger la page.

Exemples : `PHIRA` -> `phira.png`, `YIH SHENG` -> `yih-sheng.webp`,
`EURO STAMP` -> `euro-stamp.jpg`, `Marque Exemple` -> `marque-exemple.png`.
Les ligatures oe/ae s'ecrivent avec les deux lettres.

Formats reconnus : webp, png, jpg, jpeg, svg (extensions en minuscules).
Si plusieurs formats existent pour un nom, cet ordre determine la priorite.
Preferer un fichier leger, avec un logo bien cadre sur fond blanc ou transparent.
L'affichage conserve les proportions de l'image, sans recadrage ni deformation.

Le nom reste affiche si aucun fichier correspondant n'existe, ou si son image
ne se charge pas. Aucun logo fictif n'est utilise.

Les fichiers `dega.jpg` / `de-ga.jpg` et `eurobump.jpg` / `euro-bump.jpg`
couvrent les variantes de noms deja prises en charge dans le catalogue.
Les autres logos existants ont ete copies sans modification depuis les medias
des partenaires ; leurs originaux restent utilises par la section partenaires.
